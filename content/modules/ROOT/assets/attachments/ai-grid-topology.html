Tenant User View

How inference requests are routed through the grid, from a tenant user's perspective.

Multi-Cluster Model Auth / Rate Limiting

Authentication and rate limiting are enforced centrally at the Inference Entrypoint MaaS. The Tenant Admin configures per-user quotas (e.g. 100k tokens/min) and the Grid Admin configures per-tenant aggregate quotas (e.g. 1M tokens/min). Users get their API keys from the Consumer Portal UI and call the Inference Entrypoint MaaS directly.

✓ Because every request funnels through the single Inference Entrypoint MaaS, per-user quotas are now enforced globally across the grid.
